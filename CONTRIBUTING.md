# Contribuir — antes de alterar

1. Respeitar a autoria ALFCYBERCOP e o contexto histórico.
2. Distinguir facto, evidência, hipótese e trabalho futuro.
3. Manter dados privados em `local-private/`, nunca no Git.
4. Criar marcos e incidentes usando `templates/`.
5. Executar `python tools/validate_repo.py` antes de propor publicação.
6. Atualizar o registo de evidências e as ligações reais verificadas.

Um Pull Request deve indicar **o que mudou, porquê, quais as fontes e o que permanece por validar**.
