# NEXI — o regresso de uma assistente local

**NEXI ≠ NEXIUS.** NEXI é um projeto de software próprio, não uma persona de conversa.

## História recuperada

- Agosto de 2026: nome atribuído e beta Windows com interface e experiências de voz.
- Final de agosto/início de setembro: identidade, memória, RBAC, Conversation Store PostgreSQL e prova de conceito de bridge.
- Nem a integração completa nem a automação permanente devem ser apresentadas como concluídas.

## Plano de reativação

1. Inventariar **sem alterar** os diretórios antigos e identificar o projeto canónico.
2. Verificar código, dependências, credenciais externas e logs, sem divulgar segredos.
3. Reproduzir o estado da beta em ambiente controlado.
4. Corrigir a bridge e as integrações PostgreSQL com testes de autenticação e auditoria.
5. Integrar com NEXUS-LAB e documentação GitHub **só depois** de demonstrar o fluxo.
